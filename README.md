# fynnjulian.github.io

Portfolio site of Fynn Baumgartner — Aerospace Engineering BSc at TUM, working
student at the DLR Institute of Robotics and Mechatronics, and a member of the
WARR aerodynamics group.

Live at <https://fynnjulian.github.io/>.

## Layout

- `index.html` — the whole site. Plain HTML, no build step and no dependencies.
- `img/` — every figure on the page.
- `projects/` — the code and reports behind the write-ups. Each project's
  "Details" panel on the site links straight to its folder here.

Published with GitHub Pages from the `main` branch, root folder.

Every figure comes from the project files themselves: plots produced by running
the scripts unchanged, figures from the original reports, and the shaded views
SolidWorks stores inside the part files.

The CAD models and the Ansys project files are not published here, since they
need the software to open. They are available on request.
